# 16. 모바일 전단 템플릿 베스트 10 재탄생 — 설계도 (2026-08-20)

> **이 문서가 소유하는 것** = 템플릿 개편의 판단 근거·확정 라인업·공통 계약·각 템플릿 상세 설계·구현 순서.
> 상태 = **M1~M5 구현 완료(2026-08-20) · 배포 대기 · 육안 검수 = 배포 후 Harold.**
> 근거 도구 = 12엔진 구조 실측(줄수·폰트·모션·sticky) + ui-ux-pro-max DB(상품유형/스타일/UX 우선순위) + frontend-design.

## §0 접수와 원칙

- 접수(Harold): "전체 템플릿 재점검 → 제대로 된 베스트 10으로 재탄생. 모바일 전단부터. 설계도 먼저."
- 원칙 셋:
  1. **양보다 정체성** — 10종이 서로 다른 장사 장면 하나씩을 소유한다. 겹치면 통합한다.
  2. **하한은 계약** — 10종 전부가 지키는 공통 골격을 코드 게이트로 고정한다(§4). 상한은 각자의 개성.
  3. **옛 발행 전단 흔들림 0** — 죽이는 코드는 REGISTRY에서만 빼고 렌더러는 남긴다(story 전례). DB 마이그레이션 0.

## §1 승부 장면 — 이 화면은 어디서 열리는가

문자로 URL을 받은 **동네 고객의 폰**에서 열린다. 랜딩페이지가 아니다.

| 순간 | 요구 |
|---|---|
| 0~3초 | 첫 화면에서 "어느 매장이 · 무엇을 · 언제까지" 판독. 히어로가 이걸 못 하면 이탈 |
| 3~30초 | 엄지 스크롤로 가격 훑기 — 가격이 상품명보다 먼저 읽혀야 한다(할인율·원 단위 구분) |
| 30초+ | 행동 — 전화·길찾기·(쿠폰·장바구니). 푸터 액션이 항상 닿아야 한다 |

UX 우선순위(ui-ux-pro-max): 대비 4.5:1↑(가격은 7:1) · 터치 44px · 가로 스크롤은 행 내 스와이프만 · 모션 150~300ms + reduced-motion · 이모지 아이콘 0(SVG 픽토그램 CT-F24만).

### §1-1 "지금 시대" 디자인 언어 — 낡음의 실측과 2026 기준 (Harold 0820 지적)

catalog_swipe 실화면(0820 스샷)에서 확인된 낡음의 실체:

| 낡은 것 (실측) | 왜 낡았나 | 2026 기준 (컬리·토스·29CM·무신사) |
|---|---|---|
| 크림/베이지 워시 배경 전면 | 2010년대 스큐어모프 잔재. 사진·가격을 죽인다 | 바탕은 **순백 / 트루블랙 / 의도된 강색** 3택. 워시는 카드 안 국소 질감으로만 |
| 한 화면에 상품 1.5개 (밀도 붕괴) | 훑기가 목적인데 스크롤만 늘림 | 2열 그리드 기본, 첫 뷰포트에 상품 4~6개 |
| "전체 1개 보기"·"더 보기" 세로 줄바꿈 | 버튼 폭 미설계 — 타이포 깨짐이 그대로 노출 | 더보기 패턴 자체를 버림 — 전체 노출 + 앵커 네비. 버튼 텍스트는 `white-space: nowrap` 계약 |
| 빈 이미지 영역 = 흰 카드 | 준비 안 된 화면으로 읽힘 | 무이미지 슬랩(픽토그램) 의무 — §4-3 |
| 가격이 배경에 묻힘 | 잉크 대비 부족 | 가격 = 화면에서 가장 무거운 검정(7:1) + 할인율만 붉은 강조 |
| 장식 헤더(WEEKLY·검색·말풍선 아이콘) | 앱 흉내 크롬 — 전단에 검색은 없다 | 크롬 제거. 헤더는 매장명·행사명·기간 3요소만 |

**전 템플릿 공통 명령**: 사진과 가격이 주인공, 배경은 무대다. 이 표의 왼쪽 열이 하나라도 남아 있으면 그 템플릿은 미완이다.

## §4 공통 골격 계약 — 10종 전부의 하한 (코드 게이트로 고정)

모든 템플릿은 6블록을 **자기 문법으로** 표현하되 반드시 가진다.

1. **헤더** — 매장명 + 행사명 + 기간. 첫 뷰포트 안에서 3요소 판독(§1의 3초 규칙).
2. **카테고리 네비** — 상품 7개+(mid 밴드)일 때 앵커/sticky/칩 중 택1.
3. **상품 카드** — 이름(계급 nm-*) · 판매가(계급 pr-* · 천단위 구분 · '원' 첨자) · 정상가 취소선+할인율(있을 때) · 원산지/규격 칩 · **무이미지 슬랩**(CT-F24 픽토그램 — 빈 회색 박스 금지).
4. **액션 푸터** — 전화·길찾기(externalLinks merge) + 매장명 재노출 + 고지 문구.
5. **시스템 호환** — 시즌 토큰 8종 오버라이드 · 밴드 3단(data-band) · variant 주입 · QR/장바구니 injection이 레이아웃을 깨지 않을 것.
6. **품질** — 본문 ≥13px(보조 라벨 ≥11px) · 가격 대비 7:1 · 터치 44px · 가로 스크롤은 행 내 스와이프만 · `prefers-reduced-motion` 전 keyframes 무력화 · 이모지 아이콘 0.
7. **시대성(§1-1 표)** — 워시 배경 전면 금지(순백/트루블랙/강색 3택) · 첫 뷰포트 상품 4~6개 · 더보기 패턴 금지(전체 노출 + 앵커) · 버튼 텍스트 nowrap · 앱 흉내 크롬(검색·말풍선) 금지.

게이트: `super-versionup-gates.test.ts`에 **골격 계약 검사**(엔진별 렌더 HTML에서 6블록 마커 grep)를 추가하고, 스모크를 10종 × 3밴드 × 이미지 유무 = 60조합으로 재편.

## §5 템플릿별 상세 설계

각 항목 = 컨셉 / 타이포(구글 폰트 한글) / 팔레트(기본 정체성 — 시즌 토큰이 오버라이드) / 구조 / 모션.

### 1. grid_hero — 위클리 메인 (폴리시)
- 컨셉: 마켓컬리급 커머스 그리드. 신뢰·정돈. 모든 매장의 안전한 기본값.
- 타이포: Noto Sans KR 900/700 유지. 가격만 tabular-nums 강화.
- 폴리시 3점: ① 히어로에 **대표 상품 실사진 1 + 최대 할인율 뱃지**(빈 다크 박스 금지) ② sticky 카테고리 칩 터치 44px ③ 카드에 100g/개당 **단가 병기**(이미 계산부 있음 — 노출 정리).

### 2. fresh_daily — 신선 데일리 (미세 손질)
- 컨셉: 오늘 들어온 신선. 딥그린 + 흰 바탕 + 큰 사진.
- 타이포: Black Han Sans 헤드 유지. 원산지 칩을 가격보다 위로(신선축은 산지가 소구).
- 손질: 히어로 카드 아래 "오늘 입고" 마이크로카피 라인 + 카드 사진比 1:1 유지.

### 3. market_board — 시장 대자보 (보강)
- 컨셉: 크림 갱지 + 붉은 인장 + 점선 리더. **사진 0장으로 성립하는 유일 축.**
- 보강 3점: ① 카테고리 사이 괘선 장식(двойная 괘선) ② 최고 할인 1품목 "오늘의 말씀" 박스 승격 ③ 합계 절약액 스탬프("오늘 다 사면 ○○원 아낍니다") — 데이터는 정상가-판매가 합산, 임의 상수 0.
- 타이포: Black Han Sans + Noto Sans KR 유지.

### 4. deal_feed — 오늘의 핫딜 (수술)
- 컨셉: 무신사 래플급 긴박. 지금 안 사면 끝.
- 타이포: **Gasoek One**(초압축 임팩트 — 신규 로드) 헤드 + Noto Sans KR.
- 팔레트: 잉크 블랙 #0A0A0B + 시그널 레드 #FF2E2E + 앰버 경고.
- 수술: ① 상단 sticky **카운트다운 바**(periodEnd 기준 — 이미 계산부 있음, 시각 존재감 재작성) ② 카드에 잔여 게이지 바(수량 데이터 없으므로 "한정수량" 라벨형 — 가짜 숫자 금지) ③ 스크롤 등장 stagger 200ms.

### 5. deal_bento — 벤또 마켓 (수술)
- 컨셉: 파스텔 벤또 그리드. 인스타 감성. 소량 상품(≤12개)에서 최강.
- 타이포: **Jua**(둥근 친근 — 신규 로드) 헤드.
- 수술: ① 블록 크기 리듬 재설계 — 1위 상품 2×2, 나머지 1×1(현재 균등 그리드의 단조 해소) ② 블록별 파스텔 8색 로테이션 유지하되 대비 검사 통과 색만 ③ large 밴드(21+)에서는 자동으로 리듬 단순화.

### 6. grid_muji — 프리미엄 셀렉트 (보강)
- 컨셉: 여백·세리프·정갈. 선물세트·고단가 상품(한우 189,000원급)의 얼굴.
- 타이포: **Hahmlet** 유지 + 가격은 Noto Sans KR 700(세리프 숫자 가독 보완).
- 보강: Exaggerated Minimalism 체크리스트 적용 — 액센트 1색만, 여백 상향, 헤드 clamp 확대.

### 7. poster_promo — 포스터 임팩트 (폴리시 — 구조 불변)
- **6매체 정합 본진이므로 골격·클래스 변경 금지.** 색·간격 토큰 폴리시만.
- 폴리시: 슬랩 모서리·스탬프 팔레트 대비 재검(7:1) + 무이미지 슬랩 질감 1단 상향.

### 8. poster_pop — 팝 아트 (폴리시)
- 컨셉: Memphis + Vibrant&Block. 개점·주년·이벤트.
- 타이포: Bagel Fat One + Black Han Sans 유지.
- 폴리시: Vibrant&Block 체크리스트(블록 gap 상향 · 대비 7:1 검증 · 스티커 회전각 통일 ±3단) + megaStrip 마퀴 reduced-motion 정지.

### 9. magazine — 매거진 스토리 (전면 재작성 · zine 흡수)
- 컨셉: 사진 좋은 매장의 브랜드 전단. 풀블리드 사진 챕터 + 잡지 표지 헤더.
- 타이포: **Gowun Batang**(세리프 본문) + Hahmlet 헤드 + IBM Plex Mono 캡션(zine 유산).
- 구조: 표지(매장명 마스트헤드 + 호수처럼 "VOL. 8월 3주") → 챕터 = 카테고리(풀블리드 대표 사진 + 세리프 리드문 = aiCopy 활용) → 상품은 2열 정물 배치 → 판권면 푸터(zine의 인쇄 미감 디테일 — 미스레지스트레이션 라인).
- 실측 결함 청산: 더보기 버튼 제거(전체 노출로 전환), 빈 다크 히어로 제거.
- **무사진 폴백**: 사진 0이면 헤더에서 market_board 추천 안내는 하지 않는다(자동 전환은 recommender 몫) — 픽토그램 정물로 성립시킨다.

### 10. catalog_dark — 다크 쇼케이스 (전면 재작성 · swipe 흡수)
- 컨셉: OLED 블랙 무대 위 상품 조명. 심야 영업·주류·정육 프리미엄.
- 타이포: **Do Hyeon**(모던 컨덴스드 — 신규 로드) 헤드 + Noto Sans KR.
- 팔레트: #050505 + 조명 앰버 #FFB020 + 시즌 토큰 액센트.
- 구조: 히어로 = 대표 상품 스포트라이트(radial 조명) → 카테고리 = **가로 스와이프 행**(swipe 유산 — 행 내 스크롤만, 스냅 + 페이드 힌트) → 가격 네온 처리 → 다크 푸터.
- 접근성: 다크 배경 위 본문 대비 재검(회색-온-블랙 금지).
