[ 핵심 4조 ]

제1조. 본 POS Agent는 매장 사장님(이하 "이용자")의 명시 동의 하에 매장 사장님 소유 PC의
       매장 사장님 소유 데이터에만 접근합니다.

제2조. 매장에서 발생한 모든 데이터(고객 정보, 매출, 재고 등)의 소유권은 매장 사장님께
       있으며, POS 시스템 공급사는 본 데이터의 소유자가 아닙니다.

제3조. POS 시스템 공급사와의 별도 계약/약관과 본 Agent의 데이터 수집이 충돌할 경우,
       매장 사장님의 데이터 자기결정권이 우선합니다.

제4조. Agent는 POS DB에 SELECT 권한만 사용하며, 원본 데이터를 변경/삭제하지 않습니다.


[ 추가 조항 ]

제5조 (수집 범위)
  Agent는 매장 사장님이 명시 동의한 다음 데이터만 수집합니다:
   1) 회원 정보 (이름, 휴대폰 번호, 생년월일, 회원 등급, 수신 동의 여부)
   2) 매출 데이터 (영수증 번호, 결제 일시, 상품명, 수량, 가격)
   3) 재고 스냅샷 (상품 코드, 현재 재고, 단위, 유통기한)
  주민등록번호, 신용카드 번호, 비밀번호는 수집 시점에 자동 마스킹되어 전송됩니다.

제6조 (전송 보안)
  - 모든 통신은 HTTPS (TLS 1.2 이상) 암호화.
  - agent_key 발급은 한줄전단AI 슈퍼관리자만 수행하며, 유출 시 즉시 무효화 가능.
  - Agent는 SELECT 외 권한을 절대 사용하지 않으며, 매장 PC의 다른 파일/프로그램에
    접근하지 않습니다.

제7조 (개인정보 보호)
  - 한줄전단AI는 개인정보보호법 및 정보통신망법을 준수합니다.
  - 수집된 개인정보는 매장 사장님의 마케팅 발송 목적으로만 사용됩니다.
  - 매장 사장님 요청 시 즉시 전체 데이터 삭제 가능합니다.

제8조 (책임 분담)
  - 매장 사장님이 POS 시스템 공급사와의 별도 계약 위반으로 분쟁이 발생할 경우,
    한줄전단AI는 도구 제공만 담당하며 분쟁 당사자가 아닙니다.
  - 매장 사장님은 본 Agent 설치 전 본인의 POS 약관을 확인할 책임이 있습니다.

제9조 (서비스 중단)
  - 한줄전단AI는 매장 사장님이 서비스 해지 요청 시 즉시 Agent 가동을 중단합니다.
  - 슈퍼관리자가 REVOKE 명령을 발행하면 Agent는 자동 자살하고 agent_key를 자가 wipe합니다.

제10조 (데이터 보존)
  - 매장 데이터는 한줄전단AI 서버에 안전하게 보관되며,
    매장 사장님 본인의 마케팅 분석 외 용도로 사용되지 않습니다.
  - 매장 사장님이 서비스를 해지하면 본인 요청 시 30일 내 전체 데이터 삭제됩니다.
