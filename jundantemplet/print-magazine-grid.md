## 2. 매핑 슬롯 명세

### 매장 / 카피
- `store.logo`, `store.name`, `store.branch`, `store.period`, `store.phone`, `store.address`, `store.qrcode`
- `copy.headline` (헤드라인에 `<em>` 1단어로 serif·민트강조), `copy.subline`
- `footer.member`, `footer.notice`

### 영웅 상품 `product[0..2]` (다크 헤로)
- `product[N].category` — "MEAT · 정육" 등
- `product[N].image` (1:1 누끼)
- `product[N].name` (14자)
- `product[N].unit`
- `product[N].original` (취소선, 선택)
- `product[N].price` (30px, 빨강)
- `product[N].badge` ("BEST"/"FRESH"/"SEASON")

### 그리드 상품 `product[3..32]` (5 카테고리 × 6)
- 동일 스키마, 가격 17px
- 배지: `bg`(검정 PB/일반), `bg r`(빨강 1+1/할인율), `bg g`(딥그린 친환경/SEASON)

### 카테고리 섹션
각 `<section class="cs" data-category="...">` 단위:
- 헤더 번호(`01`-`05`) + 한글명 + 영문 라벨 + 아이템 수
- 6열 그리드 (`.cs-grid`)

## 4. 인쇄 사양 체크리스트

- [x] B3 378 × 528mm + 도련 2mm
- [x] 다크 헤로 = 인쇄 시 K90 + C30 권장 (TAC 280% 이하 유지)
- [x] 본문 K100, 가격만 빨강, SEASON만 딥그린
- [x] 그라데이션 0건
- [x] 폰트 본문 11px 이상 (300dpi 스케일 시 충분)
- [x] 헤더·푸터 2px 굵은 룰로 영역 구분 (인쇄 시 안전 — 0.5pt 이상)

> ⚠️ **다크 헤로 풀톤 주의**: 헤로 밴드 면적 약 14% (945×190 / 945×1320). CMYK 변환 시 `C40 M30 Y30 K85` 정도로 분판 권장. 백엔드 PDF/X-1a 변환 단에서 처리.

## 5. 사장님 커스텀 변수

- `--c-accent` — 매장 컬러로 교체
- `--c-green` — 시즌별 변경 (봄=딥그린 / 여름=네이비 / 가을=버건디 / 겨울=다크초콜릿)
- 카테고리 수: 4–6 가변 (1300px 높이 내 5가 권장)
- 카테고리당 아이템 수: 6 고정 (4·8 변형 시 그리드 컬럼 조정)
- `copy.headline` 의 `<em>` — 시즌 단어(봄·여름·가을·겨울) 또는 컨셉 단어로 교체
