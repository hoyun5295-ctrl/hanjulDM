# PRINT_BENTO — 디자인 명세

> **무드**: Bento Mosaic / Asymmetric Grid
> **용도**: 시각 리듬으로 베스트셀러를 강조하는 매장 큐레이션. 동일한 정보량을 더 흥미롭게.
> **지면**: B4 단면 · 264 × 378mm
> **편집 캔버스**: 660 × 945px (백엔드 300dpi → 3,120 × 4,465px)

---

## 1. 레이아웃 구성

CSS Grid 6 cols × 9 rows + `grid-template-areas` 비대칭 모자이크:

```
┌──────┬──────┬──────┬──────┬──────┬──────┐
│              │                            │
│              │       T  (3×2)             │
│   H (3×3)    │       머스타드 TYPE        │
│   HERO       │       BANNER               │
│   이미지      ├──────┬──────┬──────┐      │
│   풀블리드    │  s1  │  s2  │  s3  │      │
│   오버레이    │ small│ small│ small│      │  row 1-3
├──────┬──────┼──────┼──────┼──────┼──────┤
│      │      │      │      │      │      │
│  B   │  B   │  C   │  C   │  D   │  D   │  row 4-5
│ 2×2  │ 2×2  │ 2×2  │ 2×2  │ 2×2  │ 2×2  │
├──────┴──────┴──────┼──────┴──────┼──────┤
│                    │             │      │
│      E (3×2)       │   F (2×2)   │  G   │
│      wide          │             │ 1×2  │  row 6-7
│      split         │             │ 다크 │
│      이미지+정보    │             │ 타입 │
├──────┬──────┬──────┼──────┬──────┼──────┤
│      │      │      │      │      │      │
│  I   │  I   │  J   │  J   │  K   │  K   │  row 8-9
│ 2×2  │ 2×2  │ 2×2  │ 2×2  │ 2×2  │ 2×2  │
└──────┴──────┴──────┴──────┴──────┴──────┘
```

**총 12 상품 타일** (H, s1, s2, s3, B, C, D, E, F, I, J, K) + **2 타입 타일** (T 머스타드, G 다크)

## 2. 매핑 슬롯 명세

### 매장 / 카피
- `store.logo`, `store.name`, `store.branch`, `store.period`, `store.phone`, `store.address`, `store.qrcode`
- `copy.headline` — T 타일 (머스타드 BG), em 강조 1단어

### 상품 슬롯 (반복)
| 슬롯 | 타입 | 비고 |
|---|---|---|
| `product[0]` | `.tile.hero` | 3×3 풀블리드 + 오버레이 카드. 가격 36px |
| `product[1..3]` | `.tile.small` | 1×1 미니 카드 (이름 + 가격만, 단위 생략 가능) |
| `product[4..6]` | `.tile.img` | 2×2 표준 이미지 카드 |
| `product[7]` | `.tile.wide-img` | 3×2 와이드 (이미지 좌 / 정보 우 분할) |
| `product[8]` | `.tile.img` | 2×2 표준 |
| `product[9..11]` | `.tile.img` | 2×2 표준 |

### 배지 컬러 룰
- `.badge` (기본 검정) — PB / 일반
- `.badge.r` (빨강) — 1+1, 할인율 (예: "30%")
- `.badge.m` (머스타드) — SEASON, NEW

### 타입 타일 (이미지 없는 시각 변주)
- **T (3×2, 머스타드)** — 헤드라인 카피. 보통 한 페이지에 하나
- **G (1×2, 다크)** — MD 코멘트 / 매장 한마디. 본명조 인용

### 푸터
- `footer.notice`, `footer.member`

## 3. 디자인 토큰

```css
--c-ink:      #1A1A1A;
--c-paper:    #FAFAFA;
--c-accent:   #E63946;      /* 가격 + 빨강 배지 */
--c-mustard:  #D4A93B;      /* T 타입 배너 */
--c-cream:    #F2EBD8;      /* 이미지 타일 underlay */
--c-dark:     #1A1A1A;      /* G 다크 타입 */

--f-dis: 'Pretendard Variable';
--f-ser: 'Noto Serif KR';    /* G 인용문 + T 이탈릭 em */
--f-mon: 'JetBrains Mono';
```

## 4. 인쇄 사양 체크리스트

- [x] B4 264 × 378mm + 도련 2mm
- [x] 머스타드 BG = C5 M30 Y85 K10 (의도된 풀톤, TAC 안전)
- [x] 다크 타일 BG = K90 + C30 권장 (TAC < 280%)
- [x] 본문 K100, 가격만 빨강
- [x] 그라데이션 0건
- [x] 시각 리듬은 사이즈 변주만 사용 (회전·블러·그림자 없음)
- [x] 본문 최소 10px (300dpi 스케일 시 24pt 이상)

## 5. 사장님 커스텀 변수

- `--c-mustard` — 시즌별 변경 (봄=머스타드 / 여름=청록 / 가을=테라코타 / 겨울=다크블루)
- T 타입 배너 — 헤드라인 자리. "주간 베스트", "특별 행사", "신규 입점" 등 자유 변경
- G 다크 타입 — MD 코멘트 / 매장 행사 안내 / 시즌 인사말
- `grid-template-areas` — 직접 수정해 더 비대칭으로 변형 가능 (단, 미디엄 타일을 4×4 이상으로 키우면 그리드 균형 깨짐)

## 6. 확장 가능 변형

- **B (블록 컬러) 변형** — 일부 이미지 타일을 단색 풀톤으로 교체해 시각 강조 (`.tile.img { background: var(--c-accent) }`)
- **2-Hero 변형** — H를 2×3 + 추가 1×3 hero로 분할 가능 (grid-template-areas 재배치)
- **카테고리 모드** — 각 타일에 `data-category` 부착 시 카테고리별 자동 색상 매핑 (백엔드에서 처리)
