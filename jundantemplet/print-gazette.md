# PRINT_GAZETTE — 디자인 명세

> **무드**: Newsprint Gazette / Broadsheet
> **용도**: 매장 큐레이션이 살아 있는 "주간 시장 신문" 컨셉. 단골에게 우편함처럼 전달되는 인상.
> **지면**: B3 단면 · 378 × 528mm
> **편집 캔버스**: 945 × 1320px (백엔드 300dpi → 4,465 × 6,236px)

## 2. 매핑 슬롯 명세

### 매장 / 카피
- `store.name` (마스트헤드 — `<em>&</em> GAZETTE` 형식으로 신문 제호화)
- `store.address`, `store.phone`, `store.qrcode`, `store.period`
- `copy.headline` (헤로 — 본명조 + 이탈릭 강조 1단어)
- `copy.subline` (deck text, 60자 권장)

### 영웅 상품 `product[0]`
- `product[0].image` (1 : 1.05 누끼, 비교적 큰 사이즈)
- `product[0].name`, `product[0].unit`, `product[0].original`, `product[0].price`
- caption ("FEATURE · 정육") — `<span class="caption">`로 카테고리 표시

### 컬럼 그리드 `product[1..14]`
- 동일 스키마. `meta` 라인에 카테고리 + 배지 인라인 가능
- 4컬럼 균등 그리드, 섹션마다 8개

### 에디터스 노트 (`.article.editorial`)
- 회색 베이지 BG, 첫 글자 드롭캡(자동, `:first-letter` CSS)
- 신문지 무드 강조용. 슬롯 없이 사장님 직접 작성 (캐릭터 강한 글귀 권장)

### 푸터
- `footer.notice`, `footer.member`

## 3. 디자인 토큰

```css
--c-ink:     #1A1812;        /* 약간 따뜻한 검정 */

--c-mute:    #6B6353;
--c-rule:    #8B7E66;        /* 신문 룰 라인 */
--c-accent:  #B83B2E;        /* 빈티지 신문 빨강 */
--c-tag:     #E0D8C4;        /* 에디토리얼 타일 BG */

--f-ser: 'Noto Serif KR';     /* 본문 전반 (신문지 무드 핵심) */
--f-dis: 'Pretendard Variable';
--f-mon: 'JetBrains Mono';
```

## 4. 인쇄 사양 체크리스트

- [x] B3 378 × 528mm + 도련 2mm
- [x] 종이 베이지(`#F1ECDF`)는 4도 배경. 실제 인쇄 시 **재생용지 / 미색모조**에 K100 인쇄 권장 (디지털용지에 베이지 잉크 풀톤 인쇄 시 TAC 위험)
- [x] 본문 K100 / 강조 빨강 `B83B2E` (= 약 C0 M85 Y75 K15)
- [x] 그라데이션 0건
- [x] 신문지 노이즈 오버레이 = 화면 프리뷰용. 인쇄 시 제거 권장 (`.pc::before { display: none }`)
- [x] 본문 본명조 13px 이상 (300dpi 스케일 시 32pt 이상)

## 5. 사장님 커스텀 변수

- `--c-paper` — 미색모조(`#F1ECDF`) / 그레이뉴스(`#E8E5DD`) / 백색모조(`#FAFAFA`)
- `--c-accent` — 매장 시그니처 컬러 (단, 본문보다 명도 낮게)
- 마스트헤드 store name — "Gazette" 외에 "Journal", "Weekly", "TIMES" 등 자유 변경
- 에디토리얼 타일 — 시즌 인사말 / MD 코멘트 / 매장 소식 / 고객 후기 자유 활용
- 칼럼 수: 3–5 가변 (CSS `.col-grid { grid-template-columns: repeat(N, 1fr) }` 조정)
